# templatizer

Templates that implement the engineering standards in `docs/engineering-principles/` (draft).

| Path | What |
|---|---|
| `templates/ai-python-template/` | Copier template for a Python service (src layout, Makefile, CI, import contracts, agent config) |
| `tools/gen_agent_rules.py` | Generates the `.claude/rules/*.md` files (security, clean-code, api-contracts, architecture, domain-code, observability) and the GitLab Duo files `.gitlab/duo/chat-rules.md` and `mr-review-instructions.yaml` from `rules.yml`; run it after the docs or the selection change, `--check` fails when outputs are stale |
| `tools/check_rule_citations.py` | Fails when a file in the template cites an unknown or retired rule ID or none at all; checks against the root `rules.yml` |
| `docs/engineering-principles/` | The engineering standards (principles) the template is built on; start at its `README.md` |
| `scripts/check_docs.py` | Checks the standards docs against their conventions; `--export` writes `rules.yml` |
| `rules.yml` | Every rule from the standards, generated by `scripts/check_docs.py --export`; input to the tools |
| `.gitlab-ci.yml` | This repo's CI: runs the generator `--check` and the citation check |

## Use

```bash
uvx --from copier copier copy --trust templates/ai-python-template <destination>
cd <destination> && git init && make install && make check
```

`--trust` is required because the template runs `uv lock` and generates `docs/api/openapi.yaml` after copying. Placeholders (`example-org/...`, `<approved-registry>`, image digests) must be replaced before real use; `grep -rn "TODO\|ASSUMPTION:\|VERIFY:"` lists what is still open.

## Regenerate agent rule files

```bash
python3 -I scripts/check_docs.py --export                              # docs -> rules.yml (repo root); the CI reads it
python3 -I tools/gen_agent_rules.py                                    # write
python3 -I tools/gen_agent_rules.py --check                            # exit 1 if stale
python3 -I tools/check_rule_citations.py                               # cited IDs exist
```

`python-style.md` and `testing.md` are copied from doc 08 and are not generated.
